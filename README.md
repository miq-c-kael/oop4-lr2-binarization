# ЛР 2 — Многопоточная бинаризация изображений

WinForms-приложение на C# (.NET 8): фильтр бинаризации изображения по порогу с замером времени однопоточной и многопоточной версии.

Вариант 8: **бинаризация по порогу** — если яркость пикселя выше порога → белый, иначе → чёрный.

## Сборка и запуск

```pwsh
dotnet build -c Release
dotnet run -c Release
```

Требуется **.NET 8 SDK** и **Windows**.

## Что внутри

- **Открыть** — загрузить .jpg / .png / .bmp.
- **Сгенерировать тест** — синтетическое изображение 3000×2000.
- **Порог** 0–255.
- **Бинаризовать** — обработка с замером времени и сравнением последовательной/параллельной версий.
- **Сохранить** результат.
